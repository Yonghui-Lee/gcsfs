## 2024-05-15 - Fast Path Exits and Normalization in gcsfs
**Learning:** Adding early fast-path exits (like checking for `:` in strings) in heavily called path resolution functions (e.g., `_strip_protocol`) offers massive performance gains by bypassing multiple string methods. However, in `gcsfs`, bypassing the loop also bypasses implicit slash handling. `fsspec` standardizes roots and paths without leading slashes. Fast-path exits must still include `lstrip("/")` to avoid passing malformed URIs (e.g., absolute paths like `/bucket/file.txt`) to the GCS API.
**Action:** When short-circuiting path formatting or protocol stripping functions, always verify if the short-circuit bypasses required normalization (like stripping slashes or normalizing markers) and apply those normalizations explicitly on the fast path.
