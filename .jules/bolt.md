## 2025-02-12 - Optimizing set allocations in core helper functions
**Learning:** `_coalesce_generation` is a helper function that resolves generations for API requests. It used to instantiate a `set` and call `.remove()` unconditionally for every invocation, which created a surprising amount of object allocation overhead given how small the lists of arguments typically are (e.g., 2 items). This overhead was measurable in hot paths like frequent `_info` or file operations.
**Action:** Replace unneeded collection instantiations like `set()` with simple iterative `for` loops combined with identity checks `is not None` when validating short argument lists in Python. Delay memory allocations (like instantiating `set(args)`) until they are strictly necessary, such as inside the failure/error-formatting path, to preserve exact semantic behavior (e.g., original error string formatting) without slowing down the critical happy path.
