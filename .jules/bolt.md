## 2024-05-24 - High-Frequency Native String Parsing
**Learning:** Functions like `_split_path` and `_coalesce_generation` in `gcsfs/core.py` are invoked on virtually every file operation, making them highly sensitive to object allocation (like `set()` or dictionaries) and heavy standard library function calls (like `urllib.parse.urlsplit` and `parse_qs`). Standard library parsers execute regular expressions and numerous allocations that accumulate heavily in hot paths.
**Action:** When working in foundational IO/filesystem libraries, prefer explicit, basic native string manipulations (e.g., `.find()`, `.split()`) over robust general-purpose parsers like `urlsplit` if the usage is sufficiently narrow (like searching for a single integer `generation` query param). Avoid creating temporary collections like `set()` for deduplication of tiny lists (N < 3), favoring manual variable assignment and comparisons instead.
